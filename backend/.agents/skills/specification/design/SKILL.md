# Design Skill

Start from approved Business Requirements and Technology Architecture.

1. Locate the change in the existing architecture when repository evidence exists.
2. Define the modules/components involved and their responsibilities.
3. Describe only the interactions and data/control flows that matter to the increment.
4. Identify important interfaces and design decisions.
5. Add a simple architecture diagram when it clarifies the design.
6. Keep the design implementable without becoming an exhaustive HLD/LLD document.
