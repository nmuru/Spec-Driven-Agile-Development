# Tasks Skill

Start from the approved Business Requirements, Technology Architecture, and Design.

1. Identify the implementation units required to realize the design.
2. Order tasks by dependency where necessary.
3. Keep each task concrete enough for a coding agent to execute.
4. Include repository locations when evidence supports them.
5. Include concise verification expectations.
6. Keep unresolved decisions visible rather than inventing them.

Do not add calendar estimates, sprint planning, new backlog items, or unnecessary sub-tasks.
